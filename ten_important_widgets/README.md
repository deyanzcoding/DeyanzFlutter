# ten_important_widgets

A new Flutter project, I learn 10 most important widgets in flutter that are using most in flutter every 
project, here it is : 

1) Container widget
2) Expanded widget 
3) ListTile widget 
4) CircleAvatar widget
5) Stacks widget 
6) RichText widget 
7) SizedBox widget 
8) Divider widget 
9) Padding & Align widget
10) Image widget
